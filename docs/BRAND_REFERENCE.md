# Ember brand reference

This document records the visual requirements extracted from the six-character task and sound reference. It keeps the product icon, character package, and generated previews aligned with the approved character direction.

## Source and permitted use

The canonical visual direction is the repository's six-character concept reference, supplied by the project owner. It is used only as the source for KinetiCanvas's built-in character direction. New source art must be recorded in the relevant asset package with its license and origin.

## Ember: dragon builder

Ember is the fifth character from the left in the reference lineup. The visual identifier is a plush, compact baby dragon with these traits:

- Turquoise-teal plush body and oversized round head.
- Warm ivory muzzle and belly, with dark teal feet and outer wing edges.
- Two short ivory horns, a coral center crest, and small teal crown spikes.
- Oversized glossy deep-navy eyes with bright white highlights.
- Coral round cheeks, tiny nostrils, and a joyful open mouth with a coral tongue.
- Coral wing membranes framed by teal, held as part of the character silhouette.
- Soft toy texture, rounded proportions, and a friendly, energetic expression.

The palette is teal/turquoise, warm ivory, deep navy, and coral. Favicon-sized versions may simplify texture, but must preserve Ember's rounded plush proportions, face, horn-and-crest arrangement, coral wings, and friendly expression. A generic dragon silhouette is not an acceptable substitute.

## Canonical application asset

`apps/studio/public/ember-builder.png` is the current canonical rendered Ember mark. `index.html` uses it directly as the PNG favicon, and the studio header uses the same source. `favicon.svg` remains a legacy source and must not be selected as the product favicon.

The PNG is a rendered brand preview. It does not replace the future editable Ember character package, which must follow the asset package contract in [ASSET_LIBRARY.md](ASSET_LIBRARY.md).

## Review checklist

- Compare the mark at 32 px, 64 px, 128 px, and 256 px against the reference direction.
- Verify a recognizable head, horns, coral crest, coral wings, large eyes, cheeks, and smile.
- Confirm transparent edges render cleanly on light and dark editor surfaces.
- Retain the image's accessible name: `Ember, the dragon builder`.
- Respect reduced-motion settings for any animated version of the mark.
