# Roadmap

## Milestone 0 — Foundation

- Create React, TypeScript, and Tauri package structure.
- Define JSON schemas for projects, characters, assets, motions, and export jobs.
- Add linting, type checks, test runners, CI, and fixture projects.
- Implement local storage adapters and `.kineti` package read/write.

## Milestone 1 — Editor MVP

- Implement canvas, layer list, property inspector, selection, and keyboard controls.
- Implement timeline tracks, markers, keyframes, loop region, undo/redo, and live preview.
- Create Kipi as the first fully editable asset.
- Ship idle, walk, think, work, and sleep presets.

## Milestone 2 — Asset Library And Cues

- Build Pomo, Fynn, Olli, Nixi, and Ember source packages.
- Add generic browser, design, analytics, document, terminal, and music cues.
- Add starter scene templates and visual regression baselines.

## Milestone 3 — Audio And Export

- Implement audio tracks, trimming, fades, loops, mixing, and mute controls.
- Export PNG, GIF, WebM, MP4 where supported, `.kineti`, and React/JSON code.
- Add SVG export for fully vector-compatible scenes.

## Milestone 4 — Agent Tools

- Add local MCP server and CLI.
- Add project/path permission controls and confirmation UI.
- Package the seven reusable skills.

## Milestone 5 — References And Pets

- Add image, video, GIF, website screenshot, and Figma import adapters.
- Add Pet sprite-sheet export with strict validation.

## Milestone 6 — Release

- Produce Windows, macOS, and Linux desktop builds plus the PWA.
- Complete accessibility, performance, privacy, recovery, and installer testing.
- Publish product documentation and example project packages.
